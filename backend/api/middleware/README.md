# backend/api/middleware 文件夹说明

这个文件夹放后端的「门禁检查」。

请求真正进入业务逻辑前，会先经过这里做检查。

## 它主要检查什么？

- 用户有没有登录
- 登录凭证有没有过期
- 用户是不是管理员

## 常见文件

| 文件 | 做什么 |
|------|------|
| `auth.ts` | 检查登录状态和管理员权限 |

## 常见报错

| 报错 | 大概意思 |
|------|------|
| 401 | 没登录，或者登录过期 |
| 403 | 已登录，但权限不够 |

## 给非技术同学的理解

这里像后台门口的工作人员：

- 没带通行证，不能进
- 带了普通通行证，可以进普通区域
- 要进管理员后台，必须是管理员通行证

如果普通用户进不了后台，这是正常的。

如果管理员也进不了后台，就要检查账号角色和登录状态。
