# src/auth 文件夹说明

这个文件夹负责「用户是不是已经登录」这件事。

## 它管什么？

- 用户登录后，记住当前用户是谁
- 记住用户是普通用户还是管理员
- 用户退出登录时，清掉登录状态
- 页面刷新后，尽量恢复登录状态

## 主要文件

| 文件 | 做什么 |
|------|------|
| `AuthService.ts` | 负责注册、登录、退出登录这些动作 |
| `UserSession.ts` | 负责保存当前用户的登录状态 |

## 给非技术同学的理解

你可以把这里理解成 App 的「门禁记录」。

用户登录成功后，这里会记住：

- 用户账号
- 是否已登录
- 是普通用户还是管理员

如果这里状态不对，可能会出现：

- 明明登录了却又跳回登录页
- 普通用户看到了不该看的入口
- 管理员进不了后台

遇到这类问题，可以让技术同事先看这个文件夹和 `src/router`。
