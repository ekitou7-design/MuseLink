# src/lib 文件夹说明

这个文件夹放的是前端常用的「小工具」。

如果把前端页面理解成窗口和按钮，那么 `src/lib` 就是按钮背后常用的一些工具箱。

## 最重要的文件

### api.ts

负责帮前端请求后端。

简单说，页面要登录、注册、拿文物列表时，都会需要它。

它主要做三件事：

- 知道后端地址在哪里
- 自动带上登录凭证
- 请求失败时给出错误

线上部署时，后端地址通常通过这个环境变量配置：

```text
VITE_API_BASE_URL=https://你的后端网址
```

如果这个地址没配好，网页可能能打开，但登录、注册、收藏会失败。

### authClient.ts

负责账号相关请求。

包括：

- 注册
- 密码登录
- 请求验证码
- 验证码登录
- 退出登录
- 获取当前用户信息

### authUtils.ts

负责账号相关的小工具。

包括：

- 检查 MuseLink ID 格式
- 保存和清除本地 MuseLink ID
- 复制文字到剪贴板

## 给非技术同学的理解

如果你看到线上网页报错，比如：

- 登录失败
- 注册失败
- 收藏失败
- 文物列表加载不出来

问题不一定在页面本身，也可能是 `src/lib/api.ts` 找不到正确的后端。

这时要检查：

```text
VITE_API_BASE_URL
```

或者 Cloudflare Pages Functions 里的：

```text
BACKEND_API_BASE_URL
```

## 给开发同学的提醒

普通接口请求优先用 `apiFetch()`。

如果必须直接用浏览器自带的 `fetch()`，请先用 `apiUrl()` 拼接地址，避免本地正常、线上失败。
